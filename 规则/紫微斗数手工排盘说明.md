这是一份基于传统紫微斗数理论整理的**手工排盘说明**。虽然现代多使用软件排盘，但了解手工步骤能帮助你深刻理解命盘的底层逻辑。

排盘共分为 **8个核心步骤**，请按顺序操作：

### 第一步：确定出生时间（真太阳时）

- **要求**：必须准确到“时”（甚至分），且需公历转农历，并换算为**真太阳时**。
- **注意**：紫微斗数以**农历（阴历）**为准，且时辰的划分严格依赖出生地经度（例如北京时间12点，在新疆可能还是辰时）。

### 第二步：绘制命盘与安十二地支

- **画格**：准备纸张，画出“井”字形的九宫格（外围8格+中间4格合并为1格），共12个宫位。
- **安地支**：十二地支的顺序是固定不变的。从左下角（九宫格最下排中间）开始为“寅”，按顺时针方向排列：
    - 寅 → 卯 → 辰 → 巳 → 午 → 未 → 申 → 酉 → 戌 → 亥 → 子 → 丑。

### 第三步：定命宫与身宫（关键）

- **口诀**： **“顺数生月，逆数生时”** 。
- **操作**：
    1. 从“寅”宫开始，作为正月，顺时针数到你的出生月份（例如三月，则落在“辰”宫）。
    2. 以该宫（辰宫）作为子时，**逆时针**数到你的出生时辰（例如午时），最终落点即为**命宫**。
    3. **身宫**：同样是“顺数生月”，但数到出生时辰时是**顺时针**数，落点即为身宫（通常身宫落在命宫、财帛、事业、迁移、官禄、田宅之一）。

### 第四步：安十二人事宫（逆时针排列）

- **规则**：以**命宫**为起点，**逆时针**方向（反时钟方向）依次填入以下宫位：
    1. 命宫
    2. 兄弟宫
    3. 夫妻宫
    4. 子女宫
    5. 财帛宫
    6. 疾厄宫
    7. 迁移宫
    8. 仆役宫（交友宫）
    9. 官禄宫（事业宫）
    10. 田宅宫
    11. 福德宫
    12. 父母宫

### 第五步：起寅首天干（五虎遁）

- **目的**：确定“寅”宫的天干，然后顺时针排布其他宫位的天干。
- **口诀**（五虎遁）：
    - **甲己**之年丙作首（甲或己年，寅宫起“丙”）
    - **乙庚**之岁戊为头（乙或庚年，寅宫起“戊”）
    - **丙辛**必定寻庚起（丙或辛年，寅宫起“庚”）
    - **丁壬**壬位顺行流（丁或壬年，寅宫起“壬”）
    - **戊癸**何方觅，甲寅之上好追求（戊或癸年，寅宫起“甲”）
- **排布**：确定寅宫天干后，按“甲乙丙丁……”顺序顺时针填入所有宫位。

### 第六步：定五行局与紫微星

- **定五行局**：
    1. 查看**命宫**的干支（例如命宫是“戊辰”）。
    2. 对照“六十甲子纳音歌”，确定五行局。共五种：**水二局、木三局、金四局、土五局、火六局**。
    - *例如：戊辰/己巳 -> 大林木 -> 木三局。*
- **定紫微星**：
    1. 用**出生日数**除以**五行局数**（若除不尽需加减天数至能整除）。
    2. **余数/商数**决定紫微星位置：
        - 结果为1，紫微在**子**；
        - 结果为2，紫微在**丑**；
        - 以此类推，顺时针数（或根据具体流派口诀查表）。

### 第七步：排布十四主星

- **安紫微星系**（逆时针排布）：
    - 口诀：“紫微天机逆行旁，隔一阳武天同行，又隔二位廉贞地”。
    - 即：紫微 → 逆下一宫安天机 → 逆隔一宫安太阳 → 逆下一宫安武曲 → 逆下一宫安天同 → 逆隔二宫安廉贞。
- **安天府星系**（顺时针排布）：
    - 先找天府：天府永远在紫微的“三合方”或对宫（公式：若紫微在x宫，天府位置y满足 x+y=6 或 x+y=18）。
    - 口诀：“天府太阴顺贪狼，巨门天相及天梁，七杀空三破军位”。
    - 即：天府 → 顺下一宫安太阴 → 顺下一宫安贪狼……以此类推。

### 第八步：安辅曜与杂曜

- **禄存**：根据**生年天干**决定（甲年在寅，乙年在卯……）。
- **四化**（化禄、化权、化科、化忌）：根据**生年天干**决定（如甲年：廉贞化禄、破军化权……）。
- **火星/铃星**：根据**生年地支**和**生时**推算。
- **左辅/右弼**：左辅从辰宫起正月顺数生月；右弼从戌宫起正月逆数生月。

**完成以上步骤，一个基础的紫微斗数命盘即排布完成。** 后续还需安命主（生肖决定）和身主（生年决定）等星。
